# Public release checklist

- [ ] Create a public GitHub repository named `LiCSAR-WinFetch`.
- [ ] Upload the *contents* of this folder to the repository root.
- [ ] Confirm that GitHub Actions passes on Windows and Ubuntu.
- [ ] Confirm that no TIFF, `.part`, credentials, local configuration, or user paths
      are present.
- [ ] Create tag and release `v1.2.4`.
- [ ] Attach `LiCSAR-WinFetch-v1.2.4-release.zip` and its SHA-256 file if desired.
- [ ] Archive the release with Zenodo or an equivalent service.
- [ ] Add the permanent repository/release URL and DOI to the manuscript metadata.
- [ ] Add the DOI to `CITATION.cff` in a follow-up commit after it exists.
